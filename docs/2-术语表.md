## 2.5 积木块句式约定（最重要的部分）

积木标题是**带占位符的句子**，不是词条。统一句式：

| 模式 | 英文 | 中文句式 |
|---|---|---|
| 设置类 | `%1 set label %2 text %3` | `%1 设置标签 %2 文本 %3` |
| 获取类 | `%1 get gauge %2 value` | `%1 获取仪表 %2 的值` |
| 条件类 | `%1 is switch %2 %3` | `%1 开关 %2 是否%3` |
| 事件类 | `%1 on button %2 clicked: event %3 %4` | `%1 当按钮 %2 被点击时：事件 %3 %4` |
| 动作类 | `%1 start playing audio file %2 %3` | `%1 开始播放音频文件 %2 %3` |
| 文件类 | `write %1 to file %2 %3 new line at end %4` | `将 %1 写入文件 %2 %3 末尾换行 %4` |

三条硬规则：

1. **`%n` 顺序不许换**——运行时按位置替换，调序就串位。英文语序别扭时（如 `write %1 to file %2`）宁可让中文读起来稍微拗口。
2. `是否%3`、`为 %4 %5` 这类**运算符占位**后面紧跟比较符，中间不要加空格以外的字。
3. 事件类统一"当…时：事件"，冒号用全角。
